Humans_mating_habits_research_model.exe

> Description:

Streamlined research processes by migrating on-premise models to AWS by utilizizing Cloudformation, Lambda, and EC2.

> Technologies:
Cloudformation Lambda EC2 S3 SNS IAM Secret Manager Bash
> How it works:
  • Cloudformation template 1 creates the basic resources needed
  • Cloudformation template 2 is triggered by an S3 input and creates an EC2 instance to run the researchers script
  • When everything is finished running, the reseracher is alerted through email
  • Output CSV or error.txt can be accesed in output S3 bucket
