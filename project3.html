Sproutsense.exe

> Description:

SproutSense is a smart agriculture platform for real-time plant health monitoring and AI-powered irrigation recommendations using environmental sensor data.

> Achievements:
  • 1st Place — ITC 2025
  • 2nd Place — UCSB CE Capstone 2025
> Technologies:
React AWS Tailwind Docker Scikit-learn
> How it works:
  • Network of smart environmental sensors sends data to our website. Done through MQTT commmunication between Base Station and Server
  • Databse is PostgreSQL and backend is Python with FastAPI
  • Trained model in google Colab and integrated model into website
  • Build many pages and views with React
