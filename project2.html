Infrastructure_setup_for_hydro-ecological_simulation.exe

> Description:

Utilized AWS ParallelCluster with horizontal scaling and optimized SLURM configurations to significantly reduce the runtime of an R script executed within a Singularity container for UCSB researchers.

> Technologies:
ParallelCluster EC2 S3 Bash SLURM
> How it works:
  • Setup ParallelCluster
  • Create clusters and download scripts and inputs from your S3 bucket
  • Clusters run our startup scripts and then run simulationt with given inputs
  • Run script I made to consolidate files from all parallel runs in one place and concatenate them. The script also uploads output to the S3 bucket
